# Portfólio — Alberto Cabral

Portfólio pessoal de Alberto Cabral, desenvolvedor full stack júnior. O projeto apresenta habilidades, experiências profissionais e projetos selecionados, com links para contato e redes profissionais.

## Tecnologias

- [Next.js 16](https://nextjs.org/)
- React 19
- TypeScript
- Tailwind CSS 4

## Pré-requisitos

- [Node.js](https://nodejs.org/) 20.9 ou superior
- npm

## Como executar

```bash
git clone <url-do-repositorio>
cd next-easypanel
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Scripts

| Comando | Descrição |
| --- | --- |
| `npm run dev` | Inicia o servidor de desenvolvimento. |
| `npm run build` | Gera a versão otimizada para produção. |
| `npm run start` | Inicia a aplicação em produção após o build. |
| `npm run lint` | Executa a verificação de código com ESLint. |

## Estrutura do projeto

src/
